# 股票模拟交易系统交付说明

本项目使用 Vue 3、TypeScript、Node.js 和 Express，实现注册登录、模拟行情、限价委托、内存撮合、资金与持仓结算，以及 WebSocket 实时同步。用户、会话和交易数据均保存在内存中，启动时无需配置数据库。

## 二、运行与复现

### 本地开发

环境要求：Node.js **22.14+（22.x）或 24.x**、npm **10+**。

```bash
git clone https://github.com/ep-12221/stock-project.git
cd stock-project
npm ci
npm run dev
```

打开 [localhost:5173](http://localhost:5173)，注册新账户后即可进入交易页面。该命令同时启动前端和后端；后端监听 3000 端口，健康检查为 [localhost:3000/api/health](http://localhost:3000/api/health)。默认不需要 `.env` 文件，配置项见 [.env.example](../.env.example)。

如需以构建产物运行，先停止开发服务，再执行 `npm run build` 和 `npm start`，访问 [localhost:3000](http://localhost:3000)。此时 Express 同时提供前端页面、REST API 和 WebSocket，无需单独运行 Vite。

### Docker

先安装并启动 Docker Engine 或 Docker Desktop，确认 `docker info` 能显示服务端信息。在 Windows 的 WSL 中运行时，需要先启用 Docker Desktop 对当前发行版的 WSL Integration。

在项目根目录执行：

```bash
docker compose up --build -d --wait
```

打开 [localhost:3000](http://localhost:3000)。使用 `docker compose ps` 查看容器状态，`docker compose logs -f` 查看日志，`docker compose down` 停止并移除容器。

开发模式和默认 Docker 配置都使用后端 3000 端口，切换前先停止上一种运行方式。首次安装 npm 依赖、拉取基础镜像需要可用网络，耗时取决于网络与本地缓存。

## 五、实现范围与使用边界

- **状态保存在单个后端进程中。** 重启会清空用户、会话、订单、成交和幂等记录。没有数据库持久化或多实例协调。
- **交易只支持限价单。** 未实现撤单、市价单和卖空；可能与自己的挂单成交时，整笔新委托被拒绝，账户不产生部分修改。
- **随机行情与订单撮合分别处理。** 随机价格变化本身不会触发成交。默认系统挂单提供有限的演示流动性，耗尽后不自动补充，可通过 `ENABLE_DEMO_LIQUIDITY=false` 关闭。
- **重试必须沿用原请求标识与参数。** 同一标签页刷新后可以恢复待确认委托，用户确认后才会重试；关闭标签页、清空浏览器存储或更换设备后不保证恢复原标识。
